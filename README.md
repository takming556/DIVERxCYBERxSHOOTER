# DIVERxCYBERxSHOOTER
全3ステージからなる弾幕シューティングゲームです。

- 彩り豊かで美しい弾幕
- かわいいイラスト
- 魅力的なキャラクター
- インターネットと歴史にまつわる独創的なストーリー会話
- 個性あふれる3人のボスたち
- 相異なる雰囲気を放つ3曲のBGM

ネットに詳しい女の子“いちごちゃん”となって電子の海に潜り込み、彼女のパソコンに感染したウイルスの正体を突きとめに行きましょう。
弾幕シューティングと視聴覚芸術の多彩な饗宴をご堪能ください。
